# 开源与收费模式

这个仓库采用“开源核心 + 私有 Pro”的模式。

## 公开仓库

- 11 个静态页面
- 配置化品牌、主题、导航
- JSON 内容
- 本地 FAQ 检索
- 校长信箱演示
- 部署和定制文档
- MIT 许可证

公开仓库的目标是：

- 让学校零成本用起来
- 让开发者愿意 star、提 Issue、做二次开发
- 给你带来案例、流量和定制咨询

## Pro 增强包

Pro 单独授权、单独交付，源码不放进公开仓库：

- Flask 后端
- 内容管理后台
- 校长信箱持久化
- 访问统计
- 邮件通知
- 自动备份
- FAQ API
- RAG 校务助手

价格和交付方式见 Pro 包内的定价文档。公开仓库只负责说明能力和接口，不包含实现。
